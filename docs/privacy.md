# 열림알림 개인정보처리방침

시행일: 2026-07-04

**열림알림은 어떠한 개인정보도 수집하지 않습니다.**

- 계정/로그인 없음. 이름, 이메일, 전화번호 등 어떤 개인정보도 요구하지 않습니다.
- 알림 조건(관심 지역·키워드 등)은 **사용자 기기 안에만** 저장되며 외부로 전송되지 않습니다.
- 앱은 서울시 공공데이터(공공서비스예약 정보)를 GitHub에 게시된 공개 파일에서 내려받아 표시만 합니다. 이 과정에서 기기 식별자나 위치 정보를 서버로 보내지 않습니다.
- 광고·분석(애널리틱스) SDK를 사용하지 않습니다.
- 문의: sooya8922@gmail.com

## 사용 권한 안내
- **알림(POST_NOTIFICATIONS)**: 접수 오픈/신규 강좌 알림 표시
- **정확한 알람(SCHEDULE_EXACT_ALARM)**: 접수 시작 10분 전 알람의 정시성 보장
- **인터넷(INTERNET)**: 공개 강좌 데이터 다운로드
- **부팅 완료 수신(RECEIVE_BOOT_COMPLETED)**: 재부팅 후 예약된 알람 복원

## 데이터 출처
서울특별시 공공서비스예약 공공데이터(열린데이터광장, KOGL). 각 강좌의 신청은 서울시 예약 사이트에서 직접 이루어지며 본 앱은 링크만 제공합니다.
