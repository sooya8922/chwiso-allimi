## 5. 비공개 테스트 (Closed testing) — 12명 × 14일 ⭐ 출시 관문

1. Play Console → **테스트 → 비공개 테스트** → 새 트랙 만들기(또는 기본 alpha 트랙)
2. **테스터**: 이메일 목록으로 그룹 만들기 → 준비한 **12명 이메일 등록**
3. **국가/지역**: 대한민국(또는 전체)
4. **새 버전 만들기** → **AAB 업로드** (`app-release.aab`)
   - 첫 업로드 시 **Play 앱 서명** 사용 동의(권장) — 구글이 앱서명키 관리, 우리는 업로드키로 계속 올림
5. 출시 노트 입력(간단히) → 검토 → 출시
6. 테스터들에게 **참여 링크(opt-in URL)** 공유 → 각자 링크 눌러 "테스터 되기" → Play에서 설치
7. **12명이 opt-in 한 상태로 14일 연속 유지** → 그 후 프로덕션 신청 가능
   - 💡 팁: 12명이 실제로 설치·실행하고, 님이 피드백에 반응한 흔적이 있으면 심사 통과율↑

## 6. 프로덕션 출시 (14일 후)

1. 프로덕션 트랙 → 새 버전 → 같은 AAB(또는 최신) 업로드
2. 국가: 대한민국(원하면 전체)
3. 모든 "앱 콘텐츠" 항목 초록불 확인
4. 검토 제출 → 구글 심사(수일) → 승인 시 게시

## 참고: 버전 올릴 때
